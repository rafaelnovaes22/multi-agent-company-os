# Workshop — Long-list de verticais candidatos (SEED)

> ⚠️ **Isto NÃO é uma recomendação de mercado.** São **candidatos-semente** para a banca **expandir, cortar e pontuar** no workshop ([../06-WORKSHOP-MERCADO.md](../06-WORKSHOP-MERCADO.md)). A âncora é o **ICP já definido** ([../nucleo/company/icp.md](../nucleo/company/icp.md)): fundador R$ 1–5M, perfil "bombeiro"/TDAH, vende bem mas opera no caos, **founder-led**, **achável via scraping + cold outreach (Tier 2)**.
> O critério de seleção desta seed foi **apenas**: "onde costumam se concentrar fundadores nesse perfil e que sejam acessíveis pelo Tier 2?". **Cada linha precisa de pesquisa (data-pack) antes de pontuar.**

## Candidatos-semente (preencher o data-pack de cada um)

| # | Vertical candidato | Por que o ICP pode se concentrar aqui (hipótese a verificar) |
|---|---|---|
| 1 | Agências (marketing/performance/dev/design boutique) | muitos founders operadores, vendem bem, processo no improviso |
| 2 | E-commerce / DTC pequeno-médio | crescimento rápido sem backoffice estruturado |
| 3 | Clínicas e consultórios (saúde/estética/odonto) | dono-operador, agenda/atendimento no caos |
| 4 | Serviços profissionais (contabilidade, advocacia, arquitetura, eng.) | sócio faz tudo, processos manuais |
| 5 | Distribuidoras / atacado / importadoras pequenas | volume operacional alto, gestão na cabeça do dono |
| 6 | Indústria/manufatura leve (pequenas fábricas) | PCP e pedidos manuais |
| 7 | Educação online / infoprodutores / creators | escalam venda, operação não acompanha |
| 8 | Food service / pequenas redes / dark kitchens | operação intensa, margem apertada |
| 9 | Construção/reforma/incorporação pequena | orçamento e obra no improviso |
| 10 | Software houses / SaaS pequenos | founder técnico, comercial/ops bagunçado |
| 11 | Prestadores de serviço B2B (limpeza, manutenção, logística) | contratos recorrentes, gestão manual |
| 12 | Franqueados / pequenas redes de varejo | padronização fraca entre unidades |

## Como usar no workshop
1. **Divergência:** a banca adiciona/remove candidatos (esta lista é só o ponto de partida).
2. **Hard-filters (F1–F4):** rode o `g1-market-intel` (pré-work) por candidato — corta os que não têm pool de ICP, dor de processo ou acessibilidade Tier 2.
3. **Data-pack:** preencha [data-pack-template.md](data-pack-template.md) para a short-list (5–7).
4. **Scoring:** leve a short-list para a matriz (06 §4.2).

> Regra anti-vazamento: até o MDR-001, **nenhum** destes é "o mercado". O catálogo permanece agnóstico.
